# 問題四 · 語彙の使い方

一个离线单文件网页，用来训练 JLPT N1 问题四的词义边界和固定搭配。

## 打开

双击 `index.html`。不需要安装、不需要联网。

放到 iPhone：

1. 用隔空投送把 `index.html` 发到手机；
2. 在「文件」中点开，用 Safari 打开；
3. 点分享，再选「添加到主屏幕」。

## 四个页面

- **连线**：默认首页。用 5 个词匹配 4 个核心搭配框架。四个正确词严格来自本题四个选项对应的目标词或替代词，另保留 1 个干扰词。
- **做题**：先选原题答案，选完立即显示红绿判定、核心义、自然搭配和错误替代句；点「看答案」会直接展开解析，并把该题记为错误。
- **证据**：正面只显示目标词，先回忆“能接什么”，翻面查看核心语义、可接类别、禁用搭配、自然替代、近义词边界和来源状态。
- **记录**：查看正确率、待复习数量、错题和主要错误类型。

真题答错的词会自动进入错题列表，并按 1 天、3 天、7 天、14 天、30 天的间隔安排复习。所有记录只保存在当前浏览器的本地存储里。

## 怎么加题

题目都在 `questions.json`。每道题的核心字段如下：

```json
{
  "id": "2024-07-21",
  "year": "2024.7",
  "no": 21,
  "word": "もたらす",
  "reading": "もたらす",
  "answer": 1,
  "category": "搭配对象",
  "core": "ある結果・変化を引き起こす。",
  "trap": "中文“带来”不能整套搬到日语。",
  "options": [
    { "text": "原选项 1", "correct": true, "why": "为什么自然", "fix": "" },
    { "text": "原选项 2", "correct": false, "why": "为什么不自然", "fix": "自然改写" }
  ],
  "chunks": [
    { "ok": true, "text": "変化をもたらす" },
    { "ok": false, "text": "許可をもたらす", "fix": "許可が下りる" }
  ]
}
```

`firstPick` 可选，用来记录某次真题首答的选项编号。

改完数据后运行：

```sh
ruby tools/audit_grammar.rb
ruby build.rb
```

`audit_grammar.rb` 会逐项检查 132 题、528 个选项、528 组连线例句和证据卡文本，包括完整句、划线词形、来源追溯、框架占位符以及已知错误活用模式。`build.rb` 还会检查选项数量、正确答案唯一性、答案表一致性、四选项划线，以及每道题是否都有连线和证据。

连线题单独放在 `matches.json`。每题必须包含 4 组正确配对和 1 个干扰词，构建脚本会检查数量和重复词。每组配对的 `note` 和干扰词的 `decoyWhy` 会在检查答案后显示判断依据。

连线例句不再由“辞书形 + 语法后缀”在运行时拼接。每组 `pairs` 必须保存完整 `sentence`、实际划线词形 `highlight` 和来源 `exampleSource`：

```json
{
  "word": "遠い",
  "right": "つながり",
  "frame": "つながりが___なっている",
  "sentence": "卒業後、学生時代の友人とのつながりが徐々に遠くなっている。",
  "highlight": "遠く",
  "exampleSource": "2025-07-22 第2选项修正句"
}
```

`word` 是连线时选择的辞书形或目标词，`highlight` 是句中实际出现的活用形；两者不能混用。`frame` 必须恰好有一个 `___`，且不能在空格外重复 `word`。例句必须逐字来自对应真题原文／修正句，只有已登记的人工复核特例可以例外。

个别近义词存在多个自然搭配时，可以在配对中设置 `accepts`，并在题目级别设置 `"multi": true`。多解题允许同一个词匹配多个自然框架，按每个搭配是否成立判定。

连线检查后会把未解决的错配写入本地 `matchMistakes`。记录页的「连线错题」会显示错误框架、你选择的词和正确词，点击「去重连」可直接回到该题；再次检查全部正确后自动标记为已解决。

检查结果中的「只练错误搭配」和记录页的「只练错配」会进入错配复习模式：只显示上次错误的框架，已经连对的部分不重做。错配改对后会自动从待订正列表移除。

连线进度按题目 ID 保存在本地 `lastMatchId`。刷新或重新打开页面会回到上次的题目；第一次打开仍然从「風潮」开始。

做真题时，当前题目的 ID 会同步到连线进度，题目卡片里也可以点「练这道题的连线」，直接打开同一道题对应的搭配练习。

真题卡片同时提供「查看本题证据」，会直接跳到当前题目的证据卡；证据卡的上次查看位置也会保存在本地，不会每次从第一张开始。

右侧题目索引按场次分组（2026.7、2025.12……），每个场次列出第20～25题。索引可在「连线」和「真题」之间切换，支持按年份或目标词筛选；题目状态会以绿色（已做）、红色（未解决错题）和星标显示。手机端使用右下角「题目索引」打开侧边抽屉。

连线检查后的内容顺序是：原题四选项 → 做题思路（词＋中文词义） → 搭配例句和证据。

完整搭配证据放在 `evidence.json`，包括语义类别、典型搭配、禁用搭配、近义边界和来源。

连线题通过 `mode` 区分三种任务：`exam_repair`（真题改错）、`synonym`（近义辨析）、`multi`（多解题）。

“今日”统计固定按 `Asia/Shanghai`（北京时间）划分日历日。右上角显示距离下一场 JLPT 的倒计时，并自动滚动到 `2026-12-06`、`2027-07-04`、`2027-12-05` 中最近一场尚未结束的考试；日期表结束后显示“待公布”。

倒计时卡片同时内嵌“自嘲熊大王”的正方形白熊头像、作者账号和联系邮箱，照片使用内嵌 JPG，离线版本无需额外文件。

证据卡中的 `corpusQueries` 保存筑波语料库的检索式，方便后续补充实际检索频率和例句。
